# Análise Exploratória de Dados

EDA é a sigla para Análise Exploratória de Dados (do inglês, Exploratory Data Analysis)

É um processo fundamental e uma das primeiras etapas de qualquer projeto de análise ou aprendizado de máquina. 
O principal objetivo da EDA é ter uma compreensão profunda do conjunto de dados, explorando suas características, estrutura e qualidade, antes de aplicar técnicas estatísticas ou criar modelos preditivos.


#### Principais objetivos da EDA

- Entender os dados: Obter uma visão geral de como os dados estão organizados, seu tamanho e os tipos de variáveis (numéricas, categóricas, etc.).
- Identificar padrões e relações: Usar visualizações (gráficos, diagramas) e estatísticas descritivas para encontrar padrões, tendências e correlações entre as variáveis.
- Detectar anomalias e outliers: Encontrar valores atípicos ou anômalos que possam distorcer a análise posterior.
- Revelar problemas de qualidade: Identificar dados ausentes, erros de digitação e inconsistências que precisam ser tratados na fase de pré-processamento.
- Apoiar a tomada de decisão: Gerar insights valiosos que guiam a preparação dos dados, a escolha das variáveis e a seleção dos modelos estatísticos mais adequados.

#### Como a EDA é feita na prática?
##### A EDA é realizada usando uma combinação de estatísticas e visualizações: 

- Estatística descritiva: Cálculo de métricas como média, mediana, moda, desvio padrão e contagem de valores para resumir as características das variáveis.
- Visualização de dados: Criação de gráficos, como histogramas, box plots e gráficos de dispersão, para entender a distribuição e a relação entre as variáveis.
- Análise de variáveis: Investigação de cada variável individualmente e em relação às outras, buscando entender seu significado e impacto nos dados. 

Em resumo, a EDA é a fase de "investigação inicial" de um conjunto de dados, onde se fazem perguntas e se utilizam métodos visuais e estatísticos para obter uma compreensão clara e valiosa do que está por vir.
